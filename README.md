# 知识随机练习

全题型随机答题网页：单选题、多选题、判断题、填空题、简答题和论述题。

**在线使用：** https://lingy-eling.github.io/p-quiz-2026/

## 使用

直接打开线上链接，或下载 `index.html` 用浏览器打开。

## 说明

- 题干和答案均内嵌在 `index.html` 中，无外部依赖，单文件可离线使用。
- 选择题确认后显示对错与正确答案。
- 填空题提交后显示参考答案。
- 简答题、论述题通过“显示答案”按钮查看参考答案；原题库未提供的论述题答案会如实提示。
- 题库已将重复题目合并。
